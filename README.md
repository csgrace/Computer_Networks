# Computer Networks (CS305) 📡

A curated collection of course materials, lecture slides, lab exercises, exam resources, and a project starter for SUSTech CS305 Computer Networks.  
Whether you’re revising networking fundamentals or building a P2P file transfer system with reliable data transfer, this repo brings everything together in one place. 🚀
